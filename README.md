# สุ่มคู่ลงสนาม — ตัวช่วยจัดคิวแบดมินตัน

เว็บหน้าเดียวสำหรับสุ่มจับคู่ตีแบดตามรายชื่อที่กรอก ไม่มี build step ไม่มี dependency
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

## ความสามารถ

- กรอกรายชื่อผู้เล่น (บรรทัดละคน หรือคั่นด้วย `,`) ตัดชื่อซ้ำอัตโนมัติ
- เลือกรูปแบบ **เดี่ยว 1:1** (2 คน/สนาม) หรือ **คู่ 2:2** (4 คน/สนาม)
- เลือกจำนวนสนาม **1–4 สนาม**
- ชื่อไม่ซ้ำกันภายในรอบเดียวกันเสมอ
- วิธีจัดตาราง 2 แบบ
  - **สุ่มล้วน** — สุ่มใหม่ทุกครั้ง คนที่ยังไม่ได้ลงจะถูกจัดให้ลงก่อนในรอบถัดไป
  - **วนครบทุกคู่** — สร้างตารางหมุนเวียนทั้งชุด ทุกคนได้จับคู่กับทุกคน (โหมดเดี่ยวคือได้เจอกันครบทุกคน)
- นับสถิติจำนวนครั้งที่ลง/พักของแต่ละคน และหมุนเวียนให้ยุติธรรม มีแถบเทียบให้เห็นว่าใครลงมาก/น้อย
- ผังสนามวาดเส้นครบชุดตามมาตรฐาน BWF — กรอบคู่/เดี่ยว เส้นเสิร์ฟสั้น เส้นเสิร์ฟยาวคู่ และเส้นกลาง
  วาดจาก `<template>` เดียวที่ทุกการ์ดโคลนไป หน่วยใน viewBox คือเซนติเมตรจริง
  สลับเดี่ยว/คู่แล้วเส้นข้างที่ใช้จริงจะสว่างขึ้น อีกคู่หรี่ลง
- หน้าตาเป็นแบบ **liquid glass** — แผงและการ์ดเป็นแผ่นโปร่งที่เบลอสิ่งที่อยู่ข้างหลัง
  มีเส้นแสงบนขอบบนและเงายกตัวออกจากพื้น ส่วนแถบปุ่มล่างบนมือถือเป็นแคปซูลลอยให้บอร์ดไหลผ่านใต้มัน
  เบราว์เซอร์ที่ไม่รองรับ `backdrop-filter` จะได้แผ่นทึบแทน (ผ่าน `@supports`) อ่านได้เหมือนกัน
- **โหมดสว่าง/มืด** ปรับตามการตั้งค่าของเครื่องเอง (`prefers-color-scheme`)
  และกดสลับเองได้ที่ปุ่มมุมขวาบน ถ้าสลับมาตรงกับที่เครื่องตั้งไว้ จะกลับไปตามเครื่องให้อัตโนมัติ
- บนมือถือ แผงตั้งค่าทั้งแผงถูกย่อเหลือบรรทัดเดียว (`12 คน · คู่ 2:2 · 2 สนาม`) แตะ “แก้ไข” จึงกางออก
  ส่วนปุ่มสุ่มลอยอยู่ล่างจอตลอด ไม่ต้องเลื่อนกลับขึ้นไปหา
- ปุ่มรีเซ็ตมี 2 ระดับ — **กดสั้น** ล้างผลจับคู่กับสถิติแต่เก็บรายชื่อไว้
  **กดค้าง 1 วินาที** (หรือ Shift+คลิก) จะถามยืนยันก่อนล้างทุกอย่างรวมรายชื่อ
- จำรายชื่อ การตั้งค่า สถิติ และผลจับคู่ล่าสุดไว้ใน localStorage ของเครื่องที่เปิด
  ปิดแท็บหรือมือถือดับจอแล้วเปิดใหม่ ก็ได้ของเดิมคืนทั้งชุด ไม่ต้องเริ่มนับหนึ่ง
  ถ้าเว้นไปเกิน 12 ชั่วโมงถือว่าคนละก๊วน สถิติจะเริ่มใหม่ แต่ยังจำรายชื่อกับการตั้งค่าไว้ให้
  (คีย์ `badminton-draw-v1` ส่วนโหมดสว่าง/มืดที่เลือกเองอยู่ที่ `badminton-theme` แยกกัน)

## หมายเหตุเรื่องการจับคู่ให้ครบ

หนึ่งแมตช์คู่ 2:2 ใช้ไป 2 คู่ ดังนั้นถ้าจำนวนคู่ทั้งหมด `n(n-1)/2` เป็นเลขคี่
(เช่น 6, 7, 10, 11 คน) จะเหลือ 1 คู่ที่ลงไม่ได้เสมอ — เป็นข้อจำกัดเชิงคณิตศาสตร์
ไม่ใช่บั๊ก ระบบให้ผลดีที่สุดเท่าที่เป็นไปได้ (เช่น 6 คน = 14 จาก 15 คู่)

## โครงสร้าง

```
index.html                ตัวเว็บทั้งหมดอยู่ในไฟล์เดียว (HTML + CSS + JS)
icon.svg                  โลโก้ลูกขนไก่ที่วาดด้วย SVG — ใช้เป็นไอคอนบนแท็บเบราว์เซอร์
logo-source.jpg           โลโก้ก๊วน “แบดมินตัน ฮับ” — ต้นฉบับของไอคอนหน้าจอโฮม
icon-180.png              apple-touch-icon สำหรับ “เพิ่มลงในหน้าจอโฮม” บน iOS
icon-192.png              ไอคอน Android และ favicon สำรองของเบราว์เซอร์เก่า
icon-512.png              ไอคอนความละเอียดสูง
icon-maskable-512.png     ไอคอนแบบ maskable ของ Android (เผื่อขอบให้โดนครอบตัด)
manifest.webmanifest      ชื่อ สี และรายการไอคอนสำหรับหน้าจอโฮม
sw.js                     service worker — ทำให้ติดตั้งเป็นแอปได้ และเปิดใช้งานตอนไม่มีเน็ต
```

ไฟล์ `icon-*.png` ครอปวงกลมโลโก้จาก `logo-source.jpg` ถ้าเปลี่ยนโลโก้ ให้ครอปใหม่ทุกขนาด
ตัว maskable เว้นขอบมากกว่าเพื่อน เพราะ Android จะครอบเป็นวงกลมหรือสี่เหลี่ยมมนแล้วแต่เครื่อง

> `viewport-fit=cover` ในแท็ก viewport เป็นตัวที่ทำให้ `env(safe-area-inset-*)` มีค่าบน iOS
> ถ้าไม่มี ค่าจะเป็น 0 เสมอ และแอปที่ติดตั้งแล้วจะวางแถบปุ่มล่างทับแถบ home indicator

> `apple-mobile-web-app-status-bar-style: black-translucent` ทำให้ iOS ทาตัวเลขนาฬิกาเป็นสีขาวเสมอ
> แถบเขียวด้านบน (`.masthead` + `.statusbar`) จึงยืดขึ้นไปคลุม `env(safe-area-inset-top)` ให้นาฬิกามีพื้นเข้มรองรับ
> ถ้าเปลี่ยนสีแถบ อย่าลืมขยับ `--brandbar`, แท็ก `theme-color` ทั้งสองอัน และค่าใน `paintChrome()` ให้ตรงกัน

> iOS ไม่รองรับทั้ง SVG และ `data:` URI สำหรับไอคอนบนหน้าจอโฮม จึงต้องมีไฟล์ PNG จริง
> คู่กับแท็ก `<link rel="apple-touch-icon">` เสมอ ไม่อย่างนั้นจะได้ภาพหน้าเว็บย่อส่วนแทนโลโก้

## ติดตั้งเป็นแอป

เว็บเป็น PWA เต็มรูปแบบ เปิดผ่าน https (เช่น GitHub Pages) แล้วจะมีปุ่ม
“ติดตั้งเป็นแอปบนเครื่อง” โผล่ขึ้นในแผงควบคุมเอง (Chrome บน Android และเดสก์ทอป)

- Android — ติดตั้งแล้วได้ WebAPK เปิดขึ้นมาเต็มจอ ไม่มีแถบ URL
- iOS — ไม่มีปุ่มติดตั้ง ให้ใช้ แชร์ → “เพิ่มไปที่หน้าจอโฮม” แทน แล้วจะเปิดเต็มจอเหมือนกัน
- ติดแล้วใช้งานตอนไม่มีเน็ตได้ เพราะ `sw.js` แคชไฟล์ทั้งหมดไว้

เวลาแก้โค้ดแล้ว deploy ใหม่ ตัวหน้าเว็บดึงจากเน็ตก่อนเสมอ จึงได้ของใหม่ตั้งแต่เปิดครั้งถัดไป
แต่ถ้าแก้ไฟล์อื่น (ไอคอน manifest) ให้ขยับ `VERSION` ใน `sw.js` ด้วย เพื่อล้างแคชเก่า

## เปิดใช้งานแบบ local

ดับเบิลคลิก `index.html` หรือ

```bash
npx serve .
```

## Deploy ด้วย GitHub Pages

push ขึ้น repo แล้วเปิดที่ **Settings → Pages → Source: Deploy from a branch → main / (root)**
เว็บจะขึ้นที่ `https://<username>.github.io/<repo>/` ภายใน 1–2 นาที
